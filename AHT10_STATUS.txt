🐛 TROUBLESHOOTING

   Issue: Sensor Not Found
   ┌─────────────────────────────────────────────────────────────┐
   │ Error: [E][AHT10] Sensor not found at address 0x38         │
   │                                                              │
   │ Solutions:                                                   │
   │ 1. Check wiring (SDA/SCL not swapped)                      │
   │ 2. Verify 3.3V power                                       │
   │ 3. Run I2C scanner to detect devices                       │
   └─────────────────────────────────────────────────────────────┘

   Issue: Calibration Failed
   ┌─────────────────────────────────────────────────────────────┐
   │ Error: [E][AHT10] Sensor not calibrated                    │
   │                                                              │
   │ Solutions:                                                   │
   │ 1. Power cycle the sensor (unplug and replug)             │
   │ 2. Wait 40ms after power-on before init                   │
   │ 3. Check I2C bus speed (should be 400kHz)                 │
   └─────────────────────────────────────────────────────────────┘

   Issue: Both OLED and AHT10 Not Working
   ┌─────────────────────────────────────────────────────────────┐
   │ Error: Both devices not responding                          │
   │                                                              │
   │ Solutions:                                                   │
   │ 1. Check I2C wiring (both share same bus)                 │
   │ 2. Verify both devices are powered                        │
   │ 3. Run I2C scanner to see what's detected                 │
   └─────────────────────────────────────────────────────────────┘

   I2C Scanner Code:
   ┌─────────────────────────────────────────────────────────────┐
   │ Wire.begin(21, 22);                                         │
   │ for(uint8_t addr = 1; addr < 127; addr++) {                │
   │     Wire.beginTransmission(addr);                           │
   │     if (Wire.endTransmission() == 0) {                      │
   │         Serial.printf("Found: 0x%02X\n", addr);             │
   │     }                                                        │
   │ }                                                            │
   │                                                              │
   │ Expected Output:                                             │
   │ Found: 0x38  (AHT10)                                        │
   │ Found: 0x3C  (OLED)                                         │
   └─────────────────────────────────────────────────────────────┘
