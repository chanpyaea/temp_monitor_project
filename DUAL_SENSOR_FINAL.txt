🎯 HOW IT WORKS

   Automatic Sensor Detection:
   ┌─────────────────────────────────────────────────────────────┐
   │ 1. Try AHT10 first (I2C address 0x38)                       │
   │    ├─→ Found? Use AHT10 (±0.3°C accuracy) ✅                │
   │    └─→ Not found? Continue to step 2...                     │
   │                                                              │
   │ 2. Try DHT22 (GPIO 4)                                       │
   │    ├─→ Found? Use DHT22 (±0.5°C accuracy) ✅                │
   │    └─→ Not found? Continue to step 3...                     │
   │                                                              │
   │ 3. No sensor found                                          │
   │    └─→ Display error with wiring help ❌                    │
   └─────────────────────────────────────────────────────────────┘

   ⭐ You don't configure anything - it just works! ⭐

🔌 WIRING OPTIONS

   Option 1: AHT10 (Recommended - More Accurate)
   ┌─────────────────────────────────────────────────────────────┐
   │ ESP32 GPIO 21 → OLED SDA + AHT10 SDA (shared I2C)          │
   │ ESP32 GPIO 22 → OLED SCL + AHT10 SCL (shared I2C)          │
   │ ESP32 3.3V    → OLED VCC + AHT10 VCC                        │
   │ ESP32 GND     → OLED GND + AHT10 GND                        │
   │                                                              │
   │ ✅ No pull-up resistor needed!                              │
   │ ✅ Only 4 connections (shared I2C bus)                      │
   │ ✅ Better accuracy (±0.3°C)                                 │
   └─────────────────────────────────────────────────────────────┘

   Option 2: DHT22 (Alternative - Still Good)
   ┌─────────────────────────────────────────────────────────────┐
   │ ESP32 GPIO 21 → OLED SDA                                    │
   │ ESP32 GPIO 22 → OLED SCL                                    │
   │ ESP32 GPIO 4  → DHT22 DATA                                  │
   │ ESP32 3.3V    → OLED VCC + DHT22 VCC                        │
   │ ESP32 GND     → OLED GND + DHT22 GND                        │
   │ 10kΩ resistor → Between DHT22 DATA and VCC                  │
   │                                                              │
   │ ⚠️  Pull-up resistor required!                              │
   │ ✅ Works with existing DHT22 projects                       │
   │ ✅ Good accuracy (±0.5°C)                                   │
   └─────────────────────────────────────────────────────────────┘

   Option 3: Both Connected (AHT10 Takes Priority)
   ┌─────────────────────────────────────────────────────────────┐
   │ Connect both sensors - AHT10 will be used automatically    │
   │ (More accurate sensor takes priority)                       │
   └─────────────────────────────────────────────────────────────┘

📊 SENSOR COMPARISON

   ┌──────────────────────┬─────────────┬─────────────┬──────────┐
   │ Feature              │ AHT10       │ DHT22       │ Winner   │
   ├──────────────────────┼─────────────┼─────────────┼──────────┤
   │ Interface            │ I2C         │ 1-Wire      │ ✅ AHT10 │
   │ Wiring               │ Shared bus  │ 3 + resistor│ ✅ AHT10 │
   │ Temp Accuracy        │ ±0.3°C      │ ±0.5°C      │ ✅ AHT10 │
   │ Humidity Accuracy    │ ±2% RH      │ ±2% RH      │ 🟰 Tie   │
   │ Response Time        │ 1 second    │ 2 seconds   │ ✅ AHT10 │
   │ Reliability          │ High        │ Moderate    │ ✅ AHT10 │
   │ Cost                 │ $2-4        │ $3-5        │ ✅ AHT10 │
   │ GPIO Pins Used       │ 0 (shared)  │ 1 (GPIO 4)  │ ✅ AHT10 │
   │ Pull-up Resistor     │ Not needed  │ Required    │ ✅ AHT10 │
   └──────────────────────┴─────────────┴─────────────┴──────────┘

   Recommendation: Use AHT10 if possible (better in almost every way!)

🐛 TROUBLESHOOTING

   Issue: No Sensor Detected
   ┌─────────────────────────────────────────────────────────────┐
   │ Error: [E][Sensor] No temperature sensor found!            │
   │                                                              │
   │ Solutions:                                                   │
   │ 1. Check AHT10 wiring (SDA=21, SCL=22, VCC, GND)           │
   │ 2. Check DHT22 wiring (DATA=4, VCC, GND + 10kΩ pull-up)    │
   │ 3. Run I2C scanner to detect AHT10                          │
   │ 4. Verify power (3.3V, not 5V)                             │
   └─────────────────────────────────────────────────────────────┘

   Issue: Wrong Sensor Detected
   ┌─────────────────────────────────────────────────────────────┐
   │ Symptom: DHT22 detected but you have AHT10                 │
   │                                                              │
   │ Solutions:                                                   │
   │ 1. Check AHT10 I2C wiring (SDA/SCL)                        │
   │ 2. Verify I2C address (should be 0x38)                     │
   │ 3. Some clones use 0x39 - update AppConfig.h               │
   └─────────────────────────────────────────────────────────────┘

   I2C Scanner (for AHT10):
   ┌─────────────────────────────────────────────────────────────┐
   │ Wire.begin(21, 22);                                         │
   │ for(uint8_t addr = 1; addr < 127; addr++) {                │
   │     Wire.beginTransmission(addr);                           │
   │     if (Wire.endTransmission() == 0) {                      │
   │         Serial.printf("Found: 0x%02X\n", addr);             │
   │     }                                                        │
   │ }                                                            │
   │                                                              │
   │ Expected: 0x38 (AHT10), 0x3C (OLED)                        │
   └─────────────────────────────────────────────────────────────┘
